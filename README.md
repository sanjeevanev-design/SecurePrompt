# SecurePrompt 🔐

**A Free AI Security Audit Prompt for Vibe Coders.**

SecurePrompt helps developers identify and fix security vulnerabilities in their existing projects using AI coding assistants.

## 🚀 What is SecurePrompt?

SecurePrompt is a reusable security audit prompt designed for Vibe Coding tools and AI coding assistants.

It instructs AI to inspect your existing project, identify potential security risks, and recommend or implement appropriate fixes without unnecessarily changing your project's architecture, design, or existing features.

## ✨ Security Checks

- API Key & Secret Protection
- Environment Configuration
- Authentication & Authorization
- Admin Route Protection
- SQL Injection Prevention
- Cross-Site Scripting (XSS)
- API Endpoint Security
- Rate Limiting
- Database Security
- File Upload Security
- Dependency Vulnerabilities
- Git Secret Exposure
- Security Headers
- Production Configuration

## 🛠️ How to Use

1. Open your existing project in an AI coding tool.
2. Copy the SecurePrompt instructions.
3. Paste them into your AI coding assistant.
4. Ask it to audit your project.
5. Review the findings and approve proposed fixes.

## 🎯 Core Principles

- Work with the existing project.
- Do not rebuild the project from scratch.
- Preserve existing architecture and features.
- Never expose API keys, passwords, or secrets.
- Explain security issues before applying fixes.
- Avoid unrelated code changes.
- Verify fixes with appropriate tests.

## 👨‍💻 Compatibility

Designed for Vibe Coding tools and AI coding assistants, including:

- Claude Code
- Cursor
- GitHub Copilot
- Gemini CLI
- Other AI-powered coding tools

Compatibility may vary depending on the tool.

## ⚠️ Disclaimer

SecurePrompt is a security assistance tool, not a replacement for professional security testing.

AI-generated security reviews may miss vulnerabilities or produce incorrect recommendations. Always review changes and test your application before production deployment.
