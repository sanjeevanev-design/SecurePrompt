# Contributing to SecurePrompt 🤝

Thank you for your interest in contributing to SecurePrompt!

SecurePrompt is an open-source AI security audit prompt designed to help Vibe Coders and developers identify and fix security vulnerabilities in their existing projects.

We welcome contributions from developers, security researchers, AI enthusiasts, and the open-source community.

## 🚀 How You Can Contribute

You can contribute by:

- Improving the security audit prompt.
- Identifying incorrect or missing security checks.
- Adding new security testing instructions.
- Improving compatibility with AI coding tools.
- Fixing documentation errors.
- Reporting bugs or suggesting improvements.
- Improving clarity and usability.

## 📌 Contribution Guidelines

Before submitting a contribution, please follow these guidelines:

1. Keep contributions simple and useful.
2. Focus on real-world application security.
3. Do not introduce unnecessary complexity.
4. Preserve the project's original purpose.
5. Avoid breaking existing prompt functionality.
6. Use clear and professional language.
7. Do not include API keys, passwords, or private information.
8. Do not submit unverified security claims.

## 🛠️ How to Contribute

1. Fork the SecurePrompt repository.
2. Create a new branch for your changes.
3. Make your improvements.
4. Review your changes carefully.
5. Submit a Pull Request.
6. Explain what you changed and why.

## 🔍 Pull Request Requirements

Every Pull Request should include:

- A clear title.
- A short description of the changes.
- The reason for the contribution.
- Relevant examples, if applicable.
- Confirmation that no secrets or sensitive information were added.

## 🛡️ Security Issues

If you discover a security vulnerability in SecurePrompt itself, please report it privately to the repository maintainer rather than publishing sensitive exploit details in a public issue.

Do not include real credentials, private data, or exploitable secrets in reports.

## 💡 Suggestions and Feedback

Ideas and constructive feedback are always welcome.

You can use GitHub Issues to:

- Suggest new features.
- Report documentation problems.
- Request security checks.
- Share compatibility feedback.
- Discuss improvements.
